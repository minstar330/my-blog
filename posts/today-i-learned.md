오늘 클로드 코드와 함께 이 블로그를 처음부터 만들었어요. 프레임워크 없이 HTML, CSS, JavaScript만 썼더니, 세 언어가 각자 무슨 일을 하는지 또렷하게 보였어요.

한 줄로 줄이면 이래요.

| 언어 | 역할 | 집에 비유하면 |
| :--- | :--- | :--- |
| HTML | 내용과 구조 | 뼈대와 벽 |
| CSS | 모양과 배치 | 페인트와 인테리어 |
| JavaScript | 동작 | 전기와 스위치 |

## HTML: 무엇이 있는지 정한다

HTML은 페이지에 **무엇이 있는지**를 적어요. 머리말, 본문, 꼬리말 같은 구조를 태그로 표시해요.

```html
<header>블로그 이름과 테마 버튼</header>
<main id="app">여기에 글이 들어가요</main>
<footer>저작권 표시</footer>
```

- `<div>`만 쓰지 않고 `<header>`, `<main>`, `<article>`처럼 **뜻이 있는 태그**를 쓰면 화면 낭독기 같은 도구도 페이지를 이해할 수 있어요.
- `<meta name="viewport">` 한 줄이 없으면 휴대폰에서 페이지가 작게 축소되어 보여요.

## CSS: 어떻게 보일지 정한다

CSS는 HTML로 만든 내용이 **어떻게 보일지**를 정해요. 색, 글자 크기, 여백, 배치가 모두 CSS의 일이에요.

```css
.post-body {
  font-size: 1.0625rem;
  line-height: 1.75;
  word-break: keep-all;
}
```

배운 것 몇 가지:

1. **CSS 변수로 다크 모드를 만들 수 있어요.** 색을 `--bg`, `--text` 같은 변수에 담아 두고, 다크 모드일 때 변수 값만 바꾸면 페이지 전체 색이 한 번에 바뀌어요.
2. **모바일부터 만들고 넓은 화면을 덧붙여요.** 기본 스타일을 휴대폰에 맞춰 쓰고, `@media (min-width: 640px)` 안에 넓은 화면용 스타일을 추가하는 방식이에요.
3. **한글은 `word-break: keep-all`이 중요해요.** 이게 없으면 단어 중간에서 줄이 바뀌어서 읽기 불편해요.
4. **읽기 좋은 글은 폭이 너무 넓지 않아요.** 한 줄에 70자 정도가 눈이 따라가기 편해요.

## JavaScript: 무엇을 할지 정한다

JavaScript는 페이지가 **움직이게** 해요. 이 블로그에서 JavaScript가 하는 일은 이런 것들이에요.

- 마크다운 파일을 불러와서 HTML로 바꿔요.
- 주소(`#/post/글이름`)를 보고 어떤 글을 보여줄지 정해요.
- 테마 버튼을 누르면 다크 모드로 바꾸고, 고른 테마를 기억해요.

```javascript
const res = await fetch('posts/index.json');
const posts = await res.json();
```

배운 것 몇 가지:

- **`fetch`는 파일을 직접 열면(`file://`) 동작하지 않아요.** 그래서 `node serve.js`로 로컬 서버를 띄워서 확인해야 해요.
- **사용자가 쓴 글을 그대로 HTML로 넣으면 위험해요.** 글 안에 `<script>`가 있으면 실행될 수 있어서, `<`와 `>` 같은 문자를 먼저 바꿔 주는 *이스케이프*가 꼭 필요해요.
- **기능별로 파일을 나누면 고치기 쉬워요.** 마크다운 변환, 테마, 주소 처리를 각각 다른 파일에 두었어요.

## 세 언어가 함께 일하는 순서

이 블로그에서 글 하나가 화면에 나오기까지는 이런 순서로 진행돼요.

1. 브라우저가 **HTML**을 읽어 뼈대를 만들어요.
2. **CSS**가 뼈대에 색과 여백을 입혀요.
3. **JavaScript**가 마크다운 글을 불러와 HTML로 바꾼 뒤 `<main>` 안에 넣어요.
4. 새로 들어간 내용에도 **CSS**가 자동으로 적용돼요.

> 내용은 HTML, 모양은 CSS, 동작은 JavaScript. 역할을 섞지 않는 것이 깔끔한 코드의 시작이에요.
